Три варіанти нової floating panel

Це окремі HTML-прототипи для обговорення. Усі варіанти виходять з однієї ідеї: одна головна дія для виділених блоків, без кнопки «Швидко покращити», з маршрутизацією в наявні executors.

Concept 1

Command Palette

Compact

Одна панель, один ввід, одна кнопка. Chips працюють як швидкі інтенти, а freeform-запит іде в router.

  • Найкомпактніший варіант
  • Підходить для досвідченого редактора
  • Потребує прозорого показу розпізнаної дії
Відкрити

Concept 2

Intent First

Guided

Спочатку категорія дії, потім уточнення. Менше магії, більше передбачуваності та контрольованого UX.

  • Сильніший для first-time use
  • Менше помилок роутинга
  • Трохи більша площа панелі
Відкрити

Concept 3

Smart Confirm

Trust

Після freeform-запиту панель коротко показує, що саме буде виконано, і дає змінити дію перед стартом.

  • Добрий баланс між AI та контролем
  • Знижує ризик хибного роутинга
  • Додає один проміжний крок
