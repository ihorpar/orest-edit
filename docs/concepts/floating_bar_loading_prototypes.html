Floating Composer / AI Working

5 prototypes for the main text-area loading effect

Each card shows the floating bar already in the active “AI working” state. The goal is to add motion to the main prompt area without making it feel noisy, consumer-chatty, or disconnected from the current clean medical-editor direction.

Clinical sweep across the text shell. Feels like active analysis, stays calm, and matches the existing blue loading language best.
