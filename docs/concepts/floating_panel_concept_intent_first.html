Concept 2 / Intent First

Менше магії,
більше контролю

Панель спочатку фіксує категорію дії, а вже потім просить уточнення. Це зменшує ризик хибного роутинга та краще пояснює, який executor буде викликано.

  • ТекстПереписати, скоротити, спростити, зробити список або таблицю.
  • ОрфографіяПрямий виклик LanguageTool без участі patch або review proposal.
  • Врізка / ВізуалЙдуть через review proposal з typed params, а не через загальний текстовий prompt.

Selected fragment

Читачеві легше довіряти тексту, коли пояснення не лише точне, а й побудоване з правильною ритмікою: одна думка, один крок, одна опора на приклад.

Саме тому редакторська правка має не просто стискати або спрощувати фрагмент. Вона має зберігати логіку аргументу і водночас підводити до наступного абзацу без розриву темпу.

Для цього інколи потрібен список, інколи врізка, а інколи достатньо лише прибрати синтаксичний шум і перевірити правопис.

Цей концепт показує панель, де користувач спочатку явно обирає клас дії, а потім задає лише потрібні для нього параметри.
